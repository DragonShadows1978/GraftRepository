## The architecture (three stages, one principle)

Principle: **the tie you prevent needs no adjudication; the tie you
declare is served by the primitive built for it; no tie happens by
accident.**

### Stage A — Admission triage (per turn, uses only router outputs)
- Exactly-one identifier-decisive candidate, or rank-1/rank-2 margin
  above the frozen threshold → **mount the winner alone** (k=1).
- Two-plus identifier hits → **declared synthesis**: mount the
  identified set knowingly; tag the arena "confusable set present."
- Zero identifier hits (ambiguous) → k=3 eager (insurance branch) —
  note: this class is EMPTY in current certified fixtures; it needs
  probes before it needs policy.
- Lineage siblings never co-mount (L2, already default-on).

### Stage B — Serve the declared ties
For declared-synthesis turns whose members are confusable
(near-tie topical scores), prefer **shuttle**: serialize the members
across grounded trips within the turn, compose the answer from
grounding notes (proven 6/6 pattern). Simultaneous residency only
when the members are NOT confusable (identifier-distinct).

### Stage C — The demand loop (recover from admission misses)
The k=1 branch's one-in-27 miss class is repaired, not prevented:
- **Live-query routing** (primary): score the model's generation-time
  query fingerprints against the full index continuously; an unmounted
  graft outranking everything mounted = fetch trigger → trip.
- **No-good-home signature** (secondary): arena attention mass
  collapsing to sinks at readout positions (witness machinery,
  repurposed).
- **Step-3 identifier audit** (net): probe/response identifiers
  hitting unmounted grafts → ledgered miss + next-turn repair.
Registered prediction (lead, pre-data): the detector race will look
like S1-vs-S2 — mechanistic wins, verbal ask underperforms.
