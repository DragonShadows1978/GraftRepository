## The claim under test
On GPT-OSS-20B (RS4, 2026-09-04) a graft seated adjacent to the live band is
read with the same attention mass as the same text fed live: fed-text minus
mounted-band mass = +0.035 on refusers, negative on controls; the earlier
"0.41 vs 0.74" was a decomposition error (live band held question + answer
too). Lead's registered prediction: **parity holds on every model that has
a GRM adapter** — the read gap is a seating/geometry effect, not a model
property. Falsifier: any model where fed-minus-mount mass on the same probe
exceeds 0.10 with seat-near-live ON, or where the served answer flips from
correct (fed) to refusal (mounted) on ≥ 2 of the panel.
